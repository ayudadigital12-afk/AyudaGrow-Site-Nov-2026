## Deployment

The staging root .htaccess is generated by scripts/build-hostinger-root.mjs and stored at deploy/hostinger-staging-root.htaccess.
Build with npm ci and npm run build, then generate the staging root rules with node scripts/build-hostinger-root.mjs.
The build adds a release query to scripts and styles to avoid stale Hostinger CDN content. Update that release value for later releases.
